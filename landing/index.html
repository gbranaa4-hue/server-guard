Who this is actually for

A real, currently-underserved niche.

A single server or small handful of machines — a reception PC, a file server, a lab server — run by someone who wants real intrusion-style detection and paged alerts, without an agent phoning out to a third party and without a recurring bill. Willing to accept provisional thresholds that improve as real data comes in, in exchange for owning the whole stack. That sits between "nothing" and "pay Datadog or Wazuh-cloud money for infrastructure you don't have."

It is not the right answer for a real multi-team on-call rotation (use PagerDuty), a compliance-driven security program (use Wazuh or a commercial XDR), or fleet-scale infrastructure (use Datadog or Netdata Cloud) — said directly, not glossed over.

Install

pip install, two commands, no infra to stand up.

# clone and install
$ git clone https://github.com/gbranaa4-hue/server-guard.git
$ cd server-guard
$ pip install -r requirements.txt
 
# first run
$ python guard.py

Full walkthrough (Grafana HUD setup, alerting webhooks, multi-host aggregation) in QUICKSTART.md. A one-command Windows installer (install.ps1) is also in the repo.
